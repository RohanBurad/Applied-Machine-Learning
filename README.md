# Applied Machine Learning 🤖
Welcome to my Machine Learning portfolio! This repository documents my transition into AI, focusing on building, training, and evaluating predictive models using the Python Data Science stack.

---

## 🎯 Repository Goal
The objective of this project is to demonstrate a deep understanding of the **Machine Learning Lifecycle**—starting from raw data and moving toward actionable insights and predictions.

---

## 🏗️ The ML Workflow
Every project in this repository follows a structured pipeline to ensure high-quality model performance:

1. **Data Acquisition:** Importing datasets (CSV, Excel, APIs).
2. **EDA (Exploratory Data Analysis):** Visualizing distributions and correlations using Matplotlib/Seaborn.
3. **Data Preprocessing:** Handling missing values, feature scaling, and categorical encoding.
4. **Model Training:** Implementing supervised and unsupervised algorithms.
5. **Evaluation:** Testing accuracy using Confusion Matrices, R2 Scores, and MSE.



---

## 📂 Project Modules (Sem 4)
### 📊 Part 1: Data Foundations
* Statistical Analysis (Mean, Median, Standard Deviation).
* Array manipulation with **NumPy**.
* Data cleaning and filtering with **Pandas**.

### 📈 Part 2: Predictive Modeling
* **Regression:** Linear and Multiple Regression for trend analysis.
* **Classification:** Logistic Regression, Decision Trees, and K-Nearest Neighbors (KNN).
* **Clustering:** Unsupervised grouping using K-Means.

### 📉 Part 3: Visualization
* Time-series plotting for Stock Price data.
* Statistical plotting for dataset distributions.
